# Cube Viewer · competitive scan · where we win faster

**Product:** KBatch Cube Viewer (Memory Glass hotpipe + bare URL)  
**Not:** terminal shell · DOJO production cluster claim · full NLP scramble

## Fast path (bare metal → viewer → teleprompter)

```
event (type | Web Speech | BroadcastChannel whisper | Grok inject)
   → GEO key-path + FORM mesh   (~20–50 µs local)
   → 13 Rubik×lang cards + contrail canvas
   → teleprompter pane + iron-line / hexterm bus out
```

| Step | Owner | Latency class |
|------|--------|----------------|
| Ingest | browser / MG / bus | frame / speech partial |
| Solve | local JS geometry + mesh | **µs** |
| View | glass UI | paint |
| Prompter | same UI + bus | instant |

## Where we can succeed *faster* (wedges)

1. **Geometry-first multilingual (µs)** — competitors wait on cloud MT; we paint pathway + key-path **before** NLP.  
2. **Language-cube pack (Σc 83.5)** — unique KBatch asset; not in Otter/DeepL.  
3. **Glass + hotpipe from Grok** — inject from coding agent into live viewer/prompter in one call.  
4. **Teleprompter multi-lang cascade** — one line in, 13 stand-ins out (FORM when mesh hits).  
5. **Honest lanes** — DOJO/Colossus as *optional status*, not fake production cluster.  
6. **Contrail / pattern flow** — visual differentiation for training, rehab, Neuralink-style demos.

## Do **not** claim (honesty)

- Production-grade simultaneous interpretation for all languages  
- DOJO/Colossus as the runtime host  
- Replacing DeepL/Google MT quality on open domain
